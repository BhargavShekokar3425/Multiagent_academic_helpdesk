# Multi-Agent Academic Helpdesk

## Overview
Local academic helpdesk for IIT Jodhpur using
Google ADK, Ollama, RAG, ChromaDB, and CSV tools.

## Objectives
- Answer academic policy queries with citations
- Retrieve course slots and instructor information
- Draft academic emails
- Refuse unsupported and out-of-scope queries
- Log unanswered questions
- Compare single-agent and multi-agent systems
